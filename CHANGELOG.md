# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-05-04

### Added
- Core "Demo Gatekeeper" scheduling logic.
- Automated Unsubscribe module with role-relevance filtering.
- Human-in-the-loop drafting protocol.
- Premium Dashboard UI (TailwindCSS/Glassmorphism).
- Comprehensive Jest testing suite with mock layers.
- Microsoft Graph API integration service.
- SQLite persistence layer for logs and state tracking.
- CI/CD pipeline via GitHub Actions.
